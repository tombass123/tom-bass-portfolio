# Selectors Support

A self-contained website project, independent of the Tom Bass Astro portfolio.

## Reopen this project

Open this folder directly in your editor, or open `selectors-support.code-workspace`. In Codex, add this folder as a separate project:

`/Users/tombass/my-portfolio/selectors-support`

## Preview

Run `npm run dev` from this folder, then visit http://localhost:4323/.

No npm install or build is needed. Python 3 serves the static files.

## Website files

- `site/index.html`: Home
- `site/about.html`: About
- `site/gallery.html`: The parties
- `site/style.css`: shared design and responsive layouts
- `site/gallery.js`: gallery interaction
- `site/assets/`: included images and artwork

The event and Instagram links point to the existing Selectors Support accounts. The project uses no files or dependencies from the Tom Bass portfolio and can be moved anywhere as a whole folder.

## Hosting later

Upload the contents of `site/` to a static website host. This project has not been published.
